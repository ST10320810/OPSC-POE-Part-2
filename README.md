Project Title: The News App

PROJECT DESCRIPTION
The News App is a modern mobile application designed to provide users with up-to-date news articles from various sources in a clean, intuitive, and user-friendly interface. The app enables 
users to stay informed on the latest news, explore trending topics, and personalize their reading experience through features such as bookmarking (favorites), search functionality, offline 
access, and theme customization.
The application utilizes Room Database (RoomDB) to locally store user-favorited articles, ensuring they can be accessed even when the user is offline. It also supports user account management
through a profile system that allows users to register new accounts, log in to existing ones, and manage their profiles.
Additionally, the app provides a dark mode/light mode toggle, enhancing usability and reducing eye strain depending on user preference or ambient lighting conditions.

PURPOSE OF THE PROJECT
The primary goal of The News App is to deliver a seamless and personalized news-reading experience that combines accessibility, interactivity, and convenience.

SPECIFICALLY THE APP AIMS TO:
- Provide real-time access to global and local news updates.
- Allow users to save (favorite) important articles for offline reading.
- Enable efficient and fast searching of news articles by keywords or topics.
- Enhance the user experience through theme customization (dark/light mode).
- Offer secure user profile management for personalization and content tracking.

By integrating these features, the project demonstrates the development of a modern Android application with robust local data persistence, network integration, and responsive UI design.

KEY FEATURES:

Userflow for the application

Login Page
 
When a user initially launches the application, they are greeted with the Login Page, which serves as the entrance point. To access the information, the user must log in with their email and password. If the user already has an account, they can enter their credentials and proceed. If users forget their password, they can select the Forgot Password option, which will initiate a password reset by email. For new users, the Sign Up button takes them to the Registration Page, where they can create an account. After successfully logging in, the user is sent to the Headlines Page, which serves as the application's main screen.


REGISTRATION PAGE 
The Registration Page allows new users to register an account before seeing the news content. The site prompts the user to provide their complete name, email address, and establish a new 
password, which must be validated in the confirm password section. This provides account security and prevents errors while inputting credentials. After filling out the form, users can finish
the process by tapping the Sign Up/Register button, which takes them to the Headlines Page as logged-in users. For individuals who accidentally navigated here or changed their minds, a Back 
to Login or Cancel option is available.

HEADLINE PAGE 
The Headlines Page serves as the app's major centre, allowing users to explore the most recent articles. This page provides a scrollable collection of news stories, each with a thumbnail image,
headline title, brief summary, and source (e.g., Axios, CNBC, The Washington Post). By touching on a headline, visitors can access the complete content. The page also has the opportunity to
"favourite" an article. This feature enables users to store stories they find interesting for later reading. Favourited articles are immediately saved on the Favourites Page for easy access.

FAVOURITES PAGE 
The Favourites Page is a customizable part of the app that displays all of the stories a user has previously saved from the Headlines Page. It acts similarly to the headlines feed, displaying
stories with a picture, title, and summary. From here, readers can tap to read the whole article or remove items from their favourites list. This ensures that visitors receive a customized 
collection of news tailored to their specific interests without having to search again.

SEARCH PAGE 
The Search Page is a valuable resource for users looking for specific stories or subjects. The top of the page features a search bar where users can enter terms such as "technology," "elections
," or "Nvidia." Once the search is completed, the app presents a list of articles that match the query. These results work in the same way as the headlines list, with options to see the full 
story or add it to your favourites. This page gives the user the ability to explore content outside the curated headline feed.

SETTINGS PANE 
The Settings Page allows users to customize their app experience. Users can view and change their full name and email address under Profile Options. Under Language Settings, the program support
s various languages and allows users to switch to their preferred language. Theme Settings allow users to switch between Light Mode and Dark Mode, changing the overall appearance and feel of 
the interface to their liking.

Additionally, Notification Settings allow users to opt in or out of receiving alerts for breaking news and updates. At the bottom of the page, there is a Help Center link that takes users to 
FAQs and customer assistance resources. To finalize any changes, the user can click the Save Changes button or cancel them.
